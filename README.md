# Bangalore Tech Salary Decoder

## Overview

The **Bangalore Tech Salary Decoder** is a data analytics project completed as part of **The Unlox Academy Live Project**. The objective was to clean, analyze, and generate business insights from a dataset containing salary information for **1,000 Bengaluru tech professionals**.

Using Python and Pandas, the project transforms raw, inconsistent HR data into meaningful salary intelligence based on job roles, experience, company type, skills, and education tier.

---

## Objectives

* Clean and preprocess a real-world styled HR dataset.
* Standardize inconsistent categorical data.
* Convert multiple salary formats into a common numeric format (LPA).
* Perform business-oriented salary analysis.
* Generate a professional salary intelligence report.

---

## Dataset

**File:** `bangalore_tech_salaries.csv`

## Project Tasks

### Task 1 – Load & Inspect

* Loaded the dataset
* Inspected data types
* Checked missing values
* Identified duplicate records
* Generated dataset summary

### Task 2 – Data Cleaning

* Renamed columns to snake_case
* Standardized job roles
* Standardized company types
* Standardized education tiers
* Standardized work modes
* Converted salary values into numeric LPA
* Removed duplicate records
* Handled missing values appropriately

### Task 3 – Business Analysis

Answered the following business questions:

* Salary distribution by role
* Salary growth by experience (SDE Backend)
* Skill premium analysis
* Company type salary comparison
* Identification of underpaid professionals

### Task 4 – Salary Intelligence Report

Created a formatted console report summarizing all key findings.

### Task 5 – Key Insights

Generated data-driven insights with actionable recommendations.

---

## Key Findings

* Product Managers recorded the highest median salary among all analyzed roles.
* Early career growth for SDE Backend professionals showed the largest salary increase between 0–1 and 2–3 years of experience.
* System Design delivered the highest salary premium among the selected technical skills.
* Unicorn companies offered significantly higher median salaries than MNCs for SDE Backend professionals.
* Several professionals were identified as earning substantially below the median salary of their peer groups.
